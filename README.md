# Temple Crowd Monitoring Intelligent System

## Project Overview

Developed a Temple Crowd Intelligence System to automate crowd monitoring, replacing manual counting with real-time entry/exit tracking and occupancy estimation for improved safety and resource management.

## Key Features

- Real-time entry/exit tracking
- Occupancy estimation
- Automated crowd monitoring
- Persistent person tracking
- 6-hour crowd prediction
- Crowd density classification
- Overcrowding alerts
- Crowd flow charts
- Prediction insights
- Downloadable CSV reports

## Technology & Methodology

- YOLOv8n (pretrained on COCO dataset)
- ByteTrack algorithm
- Ridge Regression
- Random Forest
- 3-Fold Cross Validation
- Streamlit

## System

The system uses a computer vision and machine learning pipeline for real-time person detection, persistent tracking, crowd monitoring, density classification, and 6-hour crowd prediction.

## Analytics Dashboard

Designed and deployed a Streamlit-based analytics dashboard providing:

- Crowd flow charts
- Prediction insights
- Overcrowding alerts
- Downloadable CSV reports
